## Overview

The Banking application (includes Fleeca, Blaine County Savings, Maze Bank, Lombank). Bank also has a Loans tab (credit score and payment viewer for loans originated) and a Crypto tab.

---

## Theming

Edit `ui/src/theme.css` for base colors and `ui/src/config.ts` for per-brand accents and account/loan labels, then rebuild:

```
cd ui
bun install
bun run build
```

Commit the rebuilt `ui/dist/` — that's what actually ships.

---

## Dependencies

- `pulsar_core` — framework core
- `pulsar_pwnzor` — anti-cheat check loaded alongside every resource
- `oxmysql` — account and transaction persistence
